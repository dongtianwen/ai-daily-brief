1. 分析需求：
       角色： 专业的AI技术播客主持人（专业但通俗易懂，像朋友聊天一样自然）。
       任务： 将精选的AI技术新闻改写成一段自然、流畅的中文播客讲稿。
       要求：
           风格： 专业但不晦涩，口语化表达，像朋友聊天一样自然。
           结构： 开场问候 -> 正文（逐一详细介绍） -> 结尾（简短总结和展望）。
           长度： 800-1000 个中文字符（约 4-6 分钟语音）。
           内容： 详细展开技术细节、开发意义和商业价值。加入背景介绍。重点关注 人工智能 编程、大模型、数据标注、人工智能 企业落地等领域。每个项目至少 150 字。
           格式： 纯文本，不需要 Markdown 标记。
           发音处理： 保留 "大语言模型"、"So-tah"、"Archive" 等术语（虽然列表中没有明确列出 So-tah，但提示提到了它。提供的列表有 大语言模型、Archive）。
       输入内容：
        1.  NousResearch/hermes-agent（Agent 自我成长）。
        2.  anthropics/claude-code（终端内的 人工智能 编程工具）。
        3.  Google-research/timesfm（时间序列基础模型）。
        4.  debpalash/VoiceStudio（本地 ElevenLabs 替代品）。
        5.  Archive（智能合约漏洞注入）。

2.  起草策略 - 逐个部分：

       开场： 需要抓住听众的注意力。提及今天的日期或仅仅是“大家好”。设定场景。
       项目 1：NousResearch/hermes-agent（240k+ Stars）：
           概念： 一个“成长型”代理。
           技术细节： 它不仅仅是一个静态工具；它学习用户的习惯，适应上下文，并可能使用反思或自我修正。
           商业价值： 可扩展的 人工智能 助手，长期可用性，减少摩擦。
           起草思路： 强调“成长”这一方面。这就像一个数字实习生。

       项目 2：anthropics/claude-code（143k+ Stars）：
           概念： 终端内的 人工智能 编程。
           技术细节： 理解代码库，执行命令，自动化常规任务。集成到开发工作流中。
           商业价值： 效率，减少 bug，开发者工具市场。
           起草思路： 聚焦于“终端”这一方面。它就像一个随时待命的高级副驾驶。

       项目 3：Google-research/timesfm（29k+ Stars）：
           概念： 时间序列基础模型。
           技术细节： 预训练模型，处理股票、天气、传感器数据。处理非结构化时间数据。
           商业价值： 金融，物流，预测性维护。数据科学工作流。
           起草思路： 简单解释“时间序列”。它将时间数据视为像文本一样的语言。

       项目 4：debpalash/VoiceStudio（14k+ Stars）：
           概念： 本地 ElevenLabs 替代品。
           技术细节： 语音克隆，配音，转录。本地处理（隐私/速度）。
           商业价值： 内容创作，教育，无需云 API 的企业本地部署。
           起草思路： 强调“本地”和“隐私”。这是对云端语音工具的有力补充。

       项目 5：Archive（智能合约漏洞注入）：
           概念： 利用 大语言模型 发现智能合约漏洞。
           技术细节： 创建带有已知漏洞的数据集（“黄金标准”），用于训练检测工具。逆向工程安全。
           商业价值： Web3 安全，DeFi，保护用户资金。
           起草思路： 解释为什么这很难（很难找到带有已知漏洞的真实数据）。大语言模型 帮助生成这些“坏”数据以训练“好”检测器。

       结尾： 总结趋势（代理、工具、安全）。展望未来。

3.  写作与润色（迭代过程）：

       开场： “大家好，欢迎回到今天的 人工智能 技术播客。今天我们聊聊 GitHub 上最火的几个项目，看看 人工智能 到底在往哪个方向发展。”

       项目 1（Hermes Agent）： 首先关注“成长”这一方面。它不只是聊天；它是代理。草稿： 第一个项目是 NousResearch 的 hermes-agent。它的亮点在于“成长”。不像以前那种死板的工具，这个 Agent 能理解你的习惯。这意味着什么？意味着它能越来越懂你，处理复杂任务更顺手。这对企业落地很有意义，因为个性化的 人工智能 助手是未来的方向，能大大降低使用门槛。

       项目 2（Claude Code）： 聚焦于开发者体验。草稿： 第二个是 Anthropic 的 claude-code。大家知道现在写代码很累，这个工具直接装在终端里。它能读懂你的整个代码库，帮你写代码、改 Bug，甚至执行一些常规任务。这对开发者简直是福音，能大幅提升 coding 效率。从商业角度看，这绝对是开发者工具领域的下一个大风口。

       项目 3（TimesFM）： 聚焦于 Google 和时间序列。草稿： Google Research 出了个新模型叫 TimesFM。它是专门做时间序列预测的，比如预测股市、天气或者服务器负载。以前做这个要写很多复杂的算法，现在有个预训练模型，直接拿来用。这对数据科学家和做金融、物流的企业来说，太实用了，能节省大量研发成本。

       项目 4（VoiceStudio）： 聚焦于隐私/本地。草稿： 还有一个很火的本地语音工具叫 VoiceStudio。它是对标 ElevenLabs 的开源替代品。大家知道 ElevenLabs 很强，但 VoiceStudio 的优势在于“本地运行”。这意味着你不需要把声音数据传到云端，保护隐私的同时，响应速度也更快。不管是做有声书、配音还是视频配音，这个工具都能派上大用场。
